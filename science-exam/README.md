# 愛知県型 理科エンジン

旭丘AA Learning OS の理科入試対策で使用する、非公式・オリジナル問題生成エンジンです。

- 正本: `core.mjs` / `generator.mjs` / `bridge.js`
- 実戦セット: 20問・22点（1点×18、2点×2）
- 分野: 生物・化学・物理・地学を各5問
- 応用配点: 22点中17点を実験考察・資料読解・計算・推論に設定
- 出題形式: 現行UI互換のマーク式単一選択。将来の複数選択形式をコアで扱える設計
- 品質検証: 正答再計算、選択肢重複、ID、配点、分野バランス、誤答タイプを自動検査
- 過去問本文の転載は行わず、愛知県型の構造を参考にしたオリジナル問題のみを生成
- 旧汎用理科生成器へのフォールバックは使用しない

`tests/science-exam.mjs` が大量生成QAと旧生成器の再混入防止を担当し、`scripts/verify-science-public.mjs` がGitHub Pages上の公開ファイルをSHA-256で正本と照合します。
