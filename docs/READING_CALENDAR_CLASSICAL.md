# 長文の復習カレンダーと古文の過去問確認

2026年10月24日。

## 長文

- 初めて「読了として記録」を押すと翌日（日本時間）の復習を予約する。スクロールだけでは読了扱いにしない。
- すでに明示的な日付・解除状態がある場合はその選択を保つ。過去の読了記録すべてを勝手に再予約しない。
- 「復習を終える・次回を予約」で、前回の間隔から3日後、7日後、14日後へ進む。14日後以降は14日間隔。日付は各操作日から数える。1・3・7・14日後への手動変更と解除も可能。
- カレンダーは reading の review.due を直接参照する。手動タスクを複製しないので、変更・解除・再読了で古い予定や重複が残らない。
- 月・週・予定一覧・指定日の詳細に題名と本文へのリンクを表示する。期限を過ぎた未復習の長文も一覧で確認できる。予定時間には手動の学習予定だけを集計する。
- 学習データは従来の端末内保存。オフライン準備後も登録・表示でき、既存のバックアップに含まれる。外部カレンダーとの同期やプッシュ通知ではない。

## 単語と優先順位

- 古文100語に、あやしむ・召す・すみやかなり・さとる・まめやかなり・失す・心地・こよなし・そこばく・尋ぬの10語を追加。漢文40語は維持。
- 人物関係を読む敬語と、文脈の誤解を防ぐ語の学習優先順位を見直した。IDは元の語と固定し、表示順位だけを更新。既存の暗記履歴はそのまま利用できる。
- 「過去問で確認」で今回確認した古文の語に絞れる。意味を開くと、地域と「本文」「注付き本文」「主語／動作主等の設問」を区別して表示する。
- 確認範囲は3府県・同年度4種類。網羅的な頻度調査ではないため、S/A/Bは編集上の学習優先度。「入試に出る確率」や「全国頻出順位」は主張しない。
- 注のある語も含む。単語だけの暗記で全設問を解けるという意味ではなく、実際の文章では主語・敬意の向き・理由も確かめる。
