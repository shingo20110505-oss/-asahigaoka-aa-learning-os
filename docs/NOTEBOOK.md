# ノートと手書き

- ノートを選び「ノートを削除」→「ごみ箱に移す」で通常の一覧と全体検索から外れる。「ごみ箱」で選び「ノートを戻す」と、本文・添付・全ページを復元できる。自動で完全消去する期限は設けていない。
- 「手書きノートを作る」→「手書きを始める」で開始。既存ノートは「手書きする」から続ける。
- 手書きは最初から最大化し、画面の幅に合わせる。用紙の下部はスクロールまたは「移動」で開く。「ページ全体」や倍率指定にも切り替えられる。「道具を隠す」で書く場所を広げる。
- 下部の「＋ ページ」で追加。「前」「次」またはページ選択で移動。「用紙・ページ操作」で複製、並べ替え、削除、白紙化、現在のページのPNG書き出しを行う。
- ペン、蛍光ペン、消しゴム、直線、四角、丸。色と太さを変更できる。用紙はページごとに方眼・罫線・無地を選べる。
- 指で書く設定を外すと指は移動、ペンは描画になる。2本指の移動・拡大も実装。手書き編集中の取り消し履歴は最大100操作で、ページ追加・削除・並べ替えにも使える。画面を閉じた後の取り消し履歴は保存しない。
- 全ページ・現在ページ・用紙・線を端末のIndexedDBへ自動保存。既存の単一ページ形式は1ページ目へ読み替える。ページ数に固定上限は設けないが、端末の保存容量・メモリの範囲で利用する。
- 設定のRISEバックアップには全ページとごみ箱も含まれる。PNG書き出しは現在ページの筆跡のみで、方眼や罫線は含めない。

## 保存と検証

`ink-notebook.mjs` がバージョン2のページデータと取り消しを管理。保存はノート単位のrevision照合を続け、別画面の更新・ごみ箱への移動後の書き戻しは拒否する。ごみ箱の添付も参照中として保持する。関連ノート、全体検索、英文からの既存ノート更新も削除状態を考慮する。

テスト: 旧形式の移行、バックアップ往復、ページごとの筆跡分離、複製後の独立性、削除の取り消し、並べ替え、保存競合、ノート削除・復元、添付保持。
ブラウザ: 旧筆跡保持、3ページの作成・切り替え・複製・並べ替え、ページ削除の取り消し、ノート削除後の再読込・復元、拡大とマウスでの移動、390px幅の操作領域を確認。iPad実機のペン・2本指ジェスチャーは未検証。
