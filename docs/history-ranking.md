# 社会年表の学習ランク

## 基準と範囲

このランクは、中学歴史を日本史と世界との関係・文化・社会の変化から学ぶための編集上の優先度です。入試の実測出題頻度、公式教科書の採用率、歴史的価値の大小を示しません。外部の出題統計を調査したものではありません。

- **S：まず押さえる。** 中学歴史の核、社会・政治の大きな転換、各時代を代表する文化・思想を優先します。年号の暗記だけでなく何が変わったかを学びます。
- **A：つながりを理解。** Sの原因・結果・比較・前後関係を説明する出来事や、資料を具体的に読み取る代表例を扱います。
- **B：理解を深める。** 個別の戦闘・王朝交代・工程・詳細制度など、基本の流れを理解した後の補足です。学ぶ価値が低いという意味ではありません。

分野だけで機械的に判定しません。政治史だけをS、文化史を一律Bにはせず、かな文字・国風文化・鎌倉新仏教・室町美術・桃山文化・近代文学も同じ基準で見直します。世界史も四大文明・世界宗教・市民革命などの核を優先し、個別戦役や王位継承は補足に回します。似た項目が複数ある場合、総体を示す項目を先に学び、細かな過程は後で学びます。

## 元データとの関係

既存1000件のタイトル・説明を点検し、見直しを明示できる項目をID別の補正表にしました。これは全項目を新基準で認定済みとするものではありません。表にない項目は元のlevelをそのまま使い、元ランクの根拠を後付けで説明しません。

点検ではタイトルとdetailの取り違えも見つかっています（例：ID432のルネサンスにSNSの説明）。ランク補正はタイトルが指す出来事を対象にし、説明の修正とは分けています。ランクがreviewedであっても説明・年代の史実検証済みを意味しません。内容編集で題名が変わる場合は補正表も再確認してください。

- data/history.jsonのlevelや他の値は書き換えません。
- 補正は既存ID（1〜1000）・eventの完全一致・元levelの一致をすべて満たす場合だけ適用します。
- ID1001以降の追加項目は、その行のlevelを尊重します。題名のキーワードで勝手に上書きしません。
- IDの数値と正の整数文字列は同じ扱いです。欠損・小数・空白付き・指数表記の文字列等は補正対象外です。
- reviewed=trueはこの補正表の適用を意味します。未補正はfalseです。
- 無効なlevelは表示を壊さないため仮にBとし、未確認であることを理由に明記します。
- 個人設定の上書きは利用側で行い、このモジュールには保存機能を持たせません。
