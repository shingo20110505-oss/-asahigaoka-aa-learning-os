# 画面切り替え時の状態保持

サイドメニューとスマホの下部メニューは、各グループで最後に開いた画面へ戻る。画面のDOMと操作中の状態を、このRISEを開いている間メモリに保持する。

- 長文：英文、和訳の表示、メモ、スクロール位置。ライブラリの検索・難度・ページも同じ画面内に保持。
- ノートと資料：選択、検索、教科、保管・ごみ箱の表示、詳細欄の開閉。
- 演習：問題の順番、解答、現在の問題。読解メモや設定フォームの入力途中も保持。
- 学習プラン：表示中の週。集中タイマーは経過時間を継続し、非表示中の画面更新だけ停止。
- 読書時間、読み上げ、聞き取り動画、実験のアニメーションは画面を離れると停止。音声・動画は自動再生しない。

学習記録は従来どおりIndexedDBに保存する。別画面で追加・更新されたノートなどは、復帰時に保存データの改訂番号を確認して反映する。画面のキャッシュは再読み込み・タブを閉じる操作では引き継がない。未保存のフォームを永続保存する機能ではない。

明示的な教材リンク・ライブラリリンク・戻る/進むはそのURLへ移動する。AIチャットは既存の専用ワークスペースを再利用し、認証や管理者・各ゲストの履歴管理をこのキャッシュへ移さない。

バックアップ復元前は、非表示の読書メモの保存を終えてから画面キャッシュを解放する。読み込み中の素早い切り替え、保存失敗、戻る途中の非同期処理、スクロール復元の競合は `tests/rise-view-cache.test.mjs` で検証する。

ブラウザ確認：長文→ノート→長文で、英文・和訳表示・メモ・スクロール位置を保持し、離席中の読書時間を加算しないことを確認。選択中のノート、未保存の読解メモと文の分類も保持。390px幅の下部メニューで未保存入力の保持と横方向のはみ出しがないことを確認。

## 長文の語句と暗記カード

「復習リストに保存」で語句と暗記カードを同じIndexedDBトランザクションに保存する。カードには語句、意味、該当する連語、本文の例文を入れる。同じ英文の同じ見出し語は、従来の手動追加と同じsourceキーで重複を防ぐ。別の英文の同じ語は、異なる文脈として残す。

更新後に開いたときとバックアップ復元時には、既存の復習語句のうち「覚えた」になっていないものも暗記カードへ追加する。既存カードの編集内容と復習日程は上書きしない。辞書に意味がない語句は、未確認と分かる文言で追加する。語句を復習リストから外しても、作成済みのカードは残る。
