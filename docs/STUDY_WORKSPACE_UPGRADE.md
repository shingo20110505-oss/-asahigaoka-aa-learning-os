# 学習ワークスペースの更新（2026-10-24）

## 学習機能

- ノートは本文だけで保存可能。先頭行からタイトルを付け、疑問・重要・気づきと教科を選び、復習日も記録する。復習時は本文を隠して思い出す。
- 手書きはページ一覧、文字配置、範囲選択・移動・複製・色変更、線単位の消去、添付画像を背景にする操作を追加。既存の複数ページ・取消・自動保存を維持する。保存形式は version 3。旧版は新しい形式を拒否してデータを保護する。
- ごみ箱の一括削除は確認したノートの ID と削除時刻が一致したものだけを、IndexedDB の state/files 同一トランザクションで削除する。共有添付と別途作った暗記カードを残す。
- カレンダーは月・週・一覧、日付移動、簡単な予定追加、週次繰り返し、期限切れ予定のまとめ移動、ノート復習日を表示する。
- ホームは読みかけ／復習日／未読から英語長文を勧める。既存の150本は保持。
- 国語のことばは331項目、文脈演習は309問。追加問題は独自作成で、同音語・熟語・漢字一字の意味などを収録。
- 古文100語・漢文40語を `#/classical` に収録。単語と意味に絞り、意味の開閉、10語ずつの暗記、重要度・未学習・苦手・復習日による絞り込みを用意する。進捗は既存の vocabulary 内に名前空間付きIDで保存し、バックアップ・オフラインに対応する。

## UI・チャット

- RISEのロゴを保持し、白い本文・グレーのサイドバー・落ち着いた操作ボタンに統一。
- 普通のチャットは履歴検索、会話、添付、入力を中心に表示。手書き消去・類題・画像生成の入口をAI学習ツールに分離。
- 入力欄は通常／最大化／サイドチャットで会話スクロールから分離。日本語変換中はEnterで誤送信しない。
- 同一会話の過去画像・動画フレーム・テキスト添付を入力に含める。画像は新しいものを優先し、最大24枚・1枚12MB。本文の直近30発言から外れた添付も参照対象。画像消去の対象は直近の画像だけ。
- 過去の資料を選び直して添付する操作、回答のコピー、回答をノートに保存する操作を追加。
- 通常の回答には理由や手順を十分に説明する指示を加える。短くという利用者の指定は尊重し、JSONや固定文字数に縛らない。
- 管理者・各ゲストの保存先とオフライン履歴は既存どおり分離する。モデル設定と接続ドメインは変更しない。有料APIは追加しない。
- 検索・Web閲覧は2026-10-25に削除。サイドメニュー・ホーム・教材一覧から入口を外し、旧 `#/web` はホームへ戻す。ノート・教材のアプリ内検索と、資料室のURL保存は維持する。

## 参考と限界

- 愛知県公式・令和8年度 国語問題と解答：<https://www.pref.aichi.jp/soshiki/kotogakko/r08nyuushimonndai.html>。大問2の漢字・漢字の意味・文脈語句、古文の設問を実際に確認した。著作物の長文・設問は転載していない。
- 古典の中学生向け範囲の参考：<https://www.obunsha.co.jp/product/detail/021705>。収録語・語義・配列はRISE独自。頻度統計は未集計のため、番号とS/A/Bは「入試重要度順の目安」であり「全国入試の実測出題順」ではない。漢文は高校入試全般・中学学習の補充用。
- ロイロノート公式の手書き・カード操作を参考に、独自に実装：<https://help.loilonote.app/--5d3a9bcc7260d1001781cc5e> / <https://help.loilonote.app/--6631eacaf6e6ad0023b8e28e>。
- チャットの添付再利用・入力欄の参考：<https://learn.chatgpt.com/docs/whats-new#reuse-saved-files-and-find-past-work-faster>。ChatGPTとの完全な機能互換を示すものではない。
- AIの新規回答はオンラインが必要。単語や教材・保存した学習記録はオフライン準備後に使える。画像付きチャットのオフライン閲覧には添付の端末保存が必要。
- PDF/Office本文の直接解析、MP4の音声解析は今回追加していない。スクリーンショット・テキスト・動画フレームで入力する。
- ブラウザでPC幅とスマホ幅を確認。実機iPad/Apple Pencilでの筆圧・手のひら操作は未検証。
