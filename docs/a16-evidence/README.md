# 測定記録の読み方

2026-10-26、独立したWindows Chromeプロファイルで取得した記録です。iPad A16の実測ではありません。全質問は固定のテスト入力で、本番の履歴・学習データを読み込んでいません。

- `summary.json`：各モデルの完了状態、固定10問の中央値、採点合計、オフライン起動、メモリ標本最大、実際の4往復の最終結果を集計。
- `answer-review.json`：回答原文を読む意味評価。0/1/2点と各問の理由。Codexによる評価であり、独立した人間の採点ではありません。
- `Qwen*.json`（接尾辞なし）：端末条件、固定revision、system/各質問、回答原文、token数、runtime timing、実会話、制御されたWorker終了からの回復。
- `*-offline-proof.json`：自分のHTTPサーバーを停止してページを再読み込みし、未保存URL取得失敗を確認した後の推論。Workerも外部取得を禁止。固定10問の光合成とは短縮した別プロンプトです。同一質問の反復測定には数えません。
- `*-memory.json`：独立ChromeのプロセスだけのWindowsメモリ標本。10秒間隔で、真の瞬間ピークではありません。Working Set合計は共有ページを重複計上し得て、private commitは物理RAMではありません。GPUドライバー全体は対象外。Qwen3 WebLLMは採取導入前のため欠測。
- `*-network.json`：Page-target CDPに見えた通信のみ。Worker通信を網羅しないため、モデルの転送量や外部通信がないことの証明には使いません。初期のファイルにこの注記がない場合も同様です。
- `pilot-qwen25-misapplied-thinking.json`：Qwen2.5に不適切な思考モード引数を渡した予備試行。回答品質の比較から除外。初回ロード58.02秒のみ条件を明記して参照。修正版を別途すべて再実行しています。
- `supplement-context.json`：21往復分の固定履歴による保持試験。過去のassistant文はテスト用の固定データで、21往復を実際に生成した試験ではありません。文脈4096、出力96、生成要求のタイムアウト240秒。完了しても日本語や内容が正しいとは限らないため原文を確認します。
- `supplement-delete.json`：選択したモデルの保存データ削除前後、他モデルのCache APIエントリ、無関係なキャッシュの保持、削除済みモデルのオフライン起動失敗を確認。
- `usage-checkpoints.json`：利用枠の使用率。使用70%以上（残り30%以下）で追加比較・実装を停止する条件。
- `ui/`：独立ラボの画面幅1280/820/390pxとオフライン・削除・保存の検査。画面幅は端末CPU/GPUの証明ではありません。

モデル重み、Chromeプロファイル、APIキー、認証情報は含みません。回答原文には誤答があり、解答集として使用しないでください。
