## 消化酵素の補強

理科解説本文p.89は代表的な消化酵素としてアミラーゼとペプシンを明記するため基本とした。トリプシン・リパーゼなどは中学生向け公開学習資料と科学館・PDBj等で確認し、発展に配置。全社現行教科書の採録や入試出題頻度は未調査。

|項目ID末尾|区分|分泌元／作用場所|対象・作用の区別|
|---|---|---|---|
|digestion-pepsin|基本|胃壁の胃液／胃|酸性でタンパク質をより小さな断片へ。単独で全てをアミノ酸にしない|
|digestion-trypsin|発展|すい臓のすい液／小腸|タンパク質や断片。弱アルカリ性で働きやすい。不活性の形で分泌され小腸で活性化|
|digestion-lipase|発展|すい臓のすい液／小腸|脂肪を脂肪酸とモノグリセリドなどへ。胆汁の乳化と区別|
|digestion-amylase-sites|基本|だ液腺とすい臓／主に口と小腸|デンプンの段階的消化。アミラーゼだけで全てがブドウ糖になるとしない|
|digestion-maltase / peptidase|発展|小腸の壁など|麦芽糖→ブドウ糖、小さなタンパク質断片→アミノ酸の仕上げ|

消化液図表は分泌元と作用場所が混在する表現のため、本文では両者を分けた。分子構造・残基特異性・活性化酵素の細かな名称は除外した。
