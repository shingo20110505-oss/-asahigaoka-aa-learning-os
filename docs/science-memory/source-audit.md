## 誤解・重複・除外の点検

- 酸素の助燃性と水素の可燃性、状態変化と化学変化、透明と無色、体積比と質量比を区別。
- 陽イオンは電子を失い、陰イオンは受け取る。中和しても必ず中性にはならず、中性でもイオンが残れば導電する。
- 動脈・静脈は心臓に対する流れの向きで分類。植物は昼夜とも呼吸し、細胞呼吸と換気を区別。顕性は優劣を意味しない。
- つり合いは同一物体、作用反作用は別物体。月相を地球の影と説明しない。北半球・日本からの観察条件を付記。
- IDと正規化した同一設問を全件機械検査。別教科で共通する水の状態・光合成・エネルギーなどは、問う対象や理由が違うものを残した。意味の近さまで自動で完全判定したという主張はしない。
- 水の電気分解の2：1、メンデルの3：1は条件付きの重要関係として記載。数値を入れて求める問題は作らない。

## 残る限界

全教科書本文の完全網羅、700項目それぞれの複数独立資料による裏取り、外部専門家の全件校閲は未実施。理科解説の参照は単元の主要概念を支持するもので、各カードの全ての比較例・文言がそのページに載っていることを意味しない。指導計画を教材の全文章の直接の裏付けとして扱わない。公開リンクの今後の維持は保証できない。
