# 英語リーダーとサイドチャット

2026-10-23: 元の130本のID・本文を保持し、各Levelに4本ずつ計20本追加（合計150本）。追加分には段落別和訳、根拠英文付きの選択問題を各2問用意。語数は210〜334語。Levelは語数だけでなく語彙・構文・論旨の複雑さによるRISE内の目安であり、公式入試難度ではない。

## 読むとき

- 単語を1回タップ：基本の意味・原形候補・一致した連語を表示。
- 続けて「文のしくみ」：該当する文法パターンを確認。一部の例文には手動作成した文の区切りと訳もある。
- 「復習リストに保存」：その教材の語句リストに保存。意味の表示切り替え、習得マーク、暗記カードへの追加に対応。
- 追加20本の設問：解答と根拠・解説を表示し、解答状態を端末に保存。「もう一度解く」で個別にやり直せる。
- 「本文を広く表示」、段落訳、読み上げ、従来の要約・注釈・復習予定は併用可能。

語句はRISEの語彙データを優先し、CC0のEJDictを補助に使う。形態・連語・文法はルールによる候補であり、全単語の文脈語義判定や全文の構文解析ではない。名前・新語・複合語など未収録語は、オンラインでAIに質問できる。初回ダウンロード完了後は本文・訳・辞書・設問・復習保存がオフラインでも使える。

## サイドチャット

`src/side-chat.mjs` が唯一のチャットビューを保持し、そのDOMをサイドパネルと通常のチャット画面の間で移す。二重のセッションや通信を作らず、画面の切り替え・パネルを閉じる操作で下書き・添付・回答状態を維持する。ページ再読み込みをまたぐ未送信下書きの永続化は対象外。

- 900px以上は右パネル、小さい画面は全面パネル。閉じると教材へ戻る。
- 英文の質問は選択した文とその段落だけを引用する。ノートや画像も、ユーザーが選んだものだけを添える。
- 空の入力欄から明示的に「AIで詳しく解説」を押したときは即送信。下書き・添付・処理中の回答がある場合は自動送信せず、既存の文章を残す。
- ノート・資料のプレビューはPCでチャットと並べられる。画像は下書きの添付となり、送信するまではPCのAIに送らない。
- 認証・履歴・オフラインキャッシュは既存のチャット実装を共有。管理者／個々のゲストの分離を維持する。新しいAI回答には従来どおり通信とPCの起動が必要。

## データ更新

追加教材の編集元は `scripts/reading-new-passages*.mjs`。`node scripts/build-reading-additions.mjs` で20本と索引を生成する。旧130本の抽出スクリプトを実行した場合は、続けて追加教材の生成も行う。

語彙追加は `scripts/reading-lexicon-additions.txt` を編集して `node scripts/build-reading-lexicon.mjs`。補助辞書を更新する場合は `node scripts/build-reading-dictionary.mjs`。通常のビルドは生成済みJSONをコピーし、外部辞書サイトへの通信を必要としない。

## 検証

Nodeの既存テストに、語形・連語・文法候補・引用範囲・下書き保護・追加20本の根拠と和訳段落整合の検証を追加。ビルドで既存130本のID、150本の総数、オフライン対象、ロゴのバイト一致と非公開設定の除外を確認する。

ブラウザではローカルのテスト専用AIを用いて2タップ解説、復習保存、設問の再読み込み、下書き保持、引用付き送受信、元教材への復帰、通信切断後の履歴・辞書、390px幅、資料プレビューとの並列表示を確認する。学校の実機・プロクシ環境の検証とは別。
