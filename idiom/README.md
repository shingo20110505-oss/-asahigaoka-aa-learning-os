# 慣用句・四字熟語 独立ページ

`idiom/index.html` は社会年表の一覧学習を参考にした独立ページです。

- 表形式で語句・読み・意味・高校入試ランクを同時表示
- 「語句を隠す」「意味を隠す」「両方表示」切替
- 隠したセルは個別にタップして表示/再非表示
- 慣用句 / 四字熟語、A/B/Cランクで絞り込み
- 語句・読み・意味の全文検索
- シャッフル
- 100件ずつページ送り
- スマホ用レイアウト

## ランク
A = 高校入試で特に優先して覚える語句
B = 入試・実力問題で重要
C = 発展

データは `idiom-bank.js` に格納し、画面は件数に依存せず1万件以上を扱える構成です。実データは、重複・誤義・表記揺れを監査した項目だけ追加します。
