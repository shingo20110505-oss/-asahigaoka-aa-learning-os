# 旭丘AA Learning OS v2.2.7

愛知県立旭丘高校普通科を目標に、5教科の得点力を本番で安定して発揮するためのiPhone対応PWAです。v2では英語の精密学習を維持したまま、国語・数学・理科・社会の知識幅と適応アルゴリズムを全面強化しました。

AA Readinessは公式の合格率・偏差値・合格最低点ではありません。技能別習熟、長期保持、時間内正答、転移、速度、誤答、証拠量、不確実性から作る非公式の個人内学習指標です。

## 演習と独立「入試対策」ページ

2つのモードは完全に分離しています。

| モード | 目的 | 学習中の動作 | 記録 |
| --- | --- | --- | --- |
| 適応演習 | 弱点を修正し長期保持へ移す | 1問ごとに正誤、全選択肢理由、解説を表示 | 項目別SRSと技能状態を更新 |
| 入試対策テスト | 本番での時間内再現性を測る | 試験中は正誤・解説を表示しない | 終了後に全問分析、非公式22点換算、時間内成績を保存 |

教科別演習にも教科・教科内単元・問題量（3問・8問・15問）の設定があります。選択した単元は保存され、開始後の全問題に `examUnit` として一致しているかを生成時に検査します。問題不足時も未選択単元へ戻しません。演習画面には「設定した単元」と「現在の問題の単元」を併記します。

通常演習で正解したときだけ、短く小さい音とチェック表示を出します。不正解時と入試対策テスト中は鳴らず、設定でOFFにできます。音をOFFにしても文字による正誤・解説は残り、OSの「視差効果を減らす」設定では成功アニメーションを停止します。

入試対策テストは次の3段階です。

1. 公立標準 — 教科書事項と愛知県標準形式
2. 難関公立 — 資料統合、複数段階、紛らわしい誤答
3. 旭丘レベル — 高密度の根拠判断、転移、時間制約

数学は公式・法則の暗記だけを出題し、計算問題・文章題は出題しません。LEVEL 1・2は中学公式33項目だけ、LEVEL 3は高校入試の時短・検算に使える高校公式24項目も候補に加えます。高校公式は中学校の正式な学習範囲外なので、記述・証明では中学知識から説明できることも重視します。

問題は令和8年度愛知県公表問題の時間・構成・技能をモデル化したオリジナルです。公式問題や公式得点ではありません。

入試対策ページでは、教科、3段階難度、出題範囲（全範囲・現在の既習範囲・選択単元）、単元、試験時間、問題量（ミニ・ハーフ・本番構成）を指定できます。本番構成は次を基準にします。

単元チェックを変更すると出題範囲は自動で「選択単元のみ」へ切り替わり、設定画面と試験画面の両方に対象単元を表示します。単元別出題では、国語・英語の固定問題を含む全教科で選択単元を優先し、問題不足時にも未選択単元へ戻しません。「全範囲」を選び直すと、その教科・難度で利用できる単元をすべて選択します。

- 国語：4大問・21解答操作・22点。大問二は「漢字2小問」「同じ漢字と意味関係」「文脈に合う語句」の3系統
- 数学：公式I〜III・公式暗記15問・非公式22点換算
- 理科：6大問・20解答欄・22点
- 社会：6大問・20解答欄・22点
- 英語：会話・図表・長文・案内統合の筆記40分モデル

入試対策テストの長文・対話・古文・選択肢はアプリ作成です。通常演習には、青空文庫で公開されている著作権保護期間満了作品8作品から、出典を明示した引用読解23問を追加しました。難度Level 1〜11に合わせて、明示情報の確認から論理・構成・比喩・価値判断まで設問を切り替え、同じ演習内では同一引用を繰り返しません。説明文667字・文学文591字を含む入試読解では、各問に本文根拠と読解観点を持たせ、誤答にも「言い過ぎ」「因果の飛躍」「本文外」「逆」などの誤りの型と個別理由を付けています。複数選択と部分点を扱い、試験中には採点情報を表示しません。

固定文「便利な道具を増やすだけでは…」を使う主張問題は廃止しました。通常の国語読解は寺田寅彦、夏目漱石、芥川龍之介、宮沢賢治の本文引用へ置き換え、問題ごとに作者・作品名・青空文庫URL・「著作権保護期間満了」を表示します。

## 国語10,000語索引

国立国語研究所「教育基本語彙データベース 2009B」から、配当群と複数資料での支持度を基準に10,000件を選んだ検索索引を収録します。これはアプリ内の学習範囲索引であり、文部科学省が「10,000語」を必修語数として指定したという意味ではありません。

索引語へ未監修の意味を自動付与して正誤問題にすることはせず、意味を問う能動問題は既存の監修済み語彙バンクから出題します。

## v2の4教科強化

- 国語: 古文重要語24、漢文句法16、慣用句・四字熟語24、漢字80語の意味・読み・用例に、論理読解を統合
- 数学: 中学公式33項目＋高校入試で使える高校公式24項目の計57項目を、公式名→式・使う条件の想起で反復。LEVEL 1・2は中学公式のみ、LEVEL 3と専用「高校公式暗記」で高校公式を扱い、計算・文章題は出題しない
- 理科: 生物・化学・物理・地学を各15項目、実験、表、グラフ、計算へ接続
- 社会: 地理・公民40項目と歴史99出来事を、年号、出来事、説明、因果の337学習単位へ展開。歴史は近い年代・同形式、地理・公民は同テーマの誤答を優先し、消去だけでは解けにくい選択肢にする
- 年表: Chronologia 6.3完全版（385件）を独立ページとして接続し、統合年表・同時代史・年号クイズ・並べ替え・弱点復習・参考書型解説を維持。原本への追加はAA OSへ戻るリンクとsafe-area互換CSSだけ

各項目の優先度は、愛知県入試での重要度、個人の弱点、指数型忘却リスク、推定不確実性、難度適合、転移価値、直近出題の偏りを統合します。未知の項目を探索するためBeta分布からのThompson Samplingを使います。理科の暗記事項は必要な再遭遇を妨げないよう、直近重複ペナルティを他教科より弱くしています。

v2.2.6以降、全教科の問題に安定した復習キーを持たせ、直近に正解した問題を強く下位へ送ります。1日以内を最も強く抑制し、その後は段階的に弱めます。最新の解答が不正解なら抑制を解除して復習対象へ戻し、候補不足時だけ安全に再利用します。英単語・連語、漢字、国語引用、数学公式、理科、社会、単元限定演習にも同じ方針を適用します。

v2.2.7では英語長文に「自動」「物語文」「筆者の主張」の種類設定を追加しました。物語文は物語素材だけに絞り、出来事・登場人物の変化・教訓を問います。「筆者の主張」は説明素材だけに絞り、主張・理由・具体例・結論を問います。選択値は端末内に保存され、語彙支援長文、辞書OFF実戦、「あと1セット」のすべてに反映します。

## 英語

v1.5の精密英語機能をすべて維持します。

- 18〜32語の適応型語彙診断
- Individual Lexical Coverageと推定範囲
- 重要未知語の事前提示、タップ辞書、collocation
- 長文タップ辞書で動詞の原形・過去形・過去分詞形を表示
- 長文の最終設問後に全文和訳と本文例つき重要文法解説を表示
- 英語長文の選択肢を英語に統一（解説は日本語）
- 長文導入を24種類（先頭語14系統）へ拡張し、直前と同じ先頭語を拒否、直近12題と同じ冒頭10語・高類似導入を拒否、直近50題の使用頻度を重み付き抽選へ反映
- 長文の演習難度Level 1〜11を指定値どおり本文へ反映。Level 1〜3は基礎設問、4〜7は標準、8〜9は難関公立、10〜11は旭丘レベルとして、語数・情報密度・設問技能を段階化
- 長文の種類を「自動」「物語文」「筆者の主張」から選択。物語文は人物の変化と教訓、筆者の主張は主張・根拠・具体例・結論に設問を切り替え、選択外の素材を混ぜない
- 語彙段階が低い場合も選択した長文難度を自動で下げず、重要語の事前提示とタップ辞書を独立した支援として使用
- 未知語保存は1回のタップで断定せず、本人確認・再検索・別文脈・単語問題の正誤をBeta事後分布で統合
- Evidence ID、シナリオ専用誤答、文法ゲート
- 間接疑問文ゲートは本文だけでなく、設問・全選択肢・回答途中の保存問題まで検査
- 支援付き長文から辞書OFF実戦への移行
- 二つのグラフと英文レポートを統合し、割合＋時期の組合せ、資料照合、横断推論、語順位置指定、提案判断を問うオリジナル類題。Level 1〜3は4問、4〜7は5問、8〜11は6問へ段階化
- 愛知県英語筆記40分シミュレーターの第1パートにも図表＋レポート類題を収録
- 英単語・連語の空所補充は、活用形を含めて正答語を空所へ置換し、本文中に答えが残っていないことを生成直後と全107語の回帰テストで検査

## 忘却予測と最適復習

分析画面は項目ごとの記憶安定度Sと経過日数tから R(t)=exp(-t/S) を計算し、4教科の想起可能性を表示します。これはEbbinghaus-inspired forgetting modelであり、エビングハウス本人の厳密な公式とは表示しません。

「明日の失点リスクが高い12問」は忘却だけでなく、入試重要度、技能の不確実性、転移価値、直近の偏り、所要時間を合わせて選びます。

## 学習履歴保護

保存キーは旧版と同じ asahi_learning_os_v1 です。

- v2移行前のJSON原本を端末内に完全保存
- v1.5の移行前原本と最大3世代の端末内コピーも維持
- 回答、技能、復習項目、途中問題、問題順、回答、タイマー、スクロール位置を保存
- 旧データの回答履歴上限を2,000件から10,000件へ拡張
- 移行・Importで現在の履歴件数が減る場合は保存を中止
- v2.1.0で保存済みの長文に間接疑問文が残る場合も、回答・位置・時間を保ったまま英文だけ修復
- v2.1.2の導入履歴は既存の長文履歴へ項目を追加して記録し、旧履歴は本文から安全に補完（保存キー・schema versionは変更なし）
- v2.2.6でも保存キー `asahi_learning_os_v1` とschema 4を固定し、入試・演習それぞれの教科内単元設定、長文難度設定、数学の高校公式単元、正解フィードバック設定を同じ保存領域で維持
- JSON Export / Import / Mergeと状態指紋

SafariのWebサイトデータ削除では端末内コピーも消えます。機種変更、Safariデータ削除、ホーム画面版削除、URL変更の前には、設定からJSONバックアップを端末外へ保存してください。

## iPhoneへの追加

1. 公開URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 右上の「追加」を押す
5. ホーム画面の「旭丘AA OS」から起動する

初回はオンラインで開いてください。Service Workerがapp shellを保存した後は、通信がなくても基本学習を続けられます。
